# Client & Venture Websites — Pruthvi DR

Websites I designed and built as a freelance developer (2024 – present). Each folder is a standalone site: open `index.html` in a browser. Fitgurukannada's booking form needs PHP (e.g. XAMPP) and a CallMeBot key set in `submit_booking.php`; the key and number in this repo are placeholders.

| Site | Type | What it includes | Stack |
| --- | --- | --- | --- |
| [Adithya — Creative Portfolio](adithya-portfolio/) | Personal portfolio for a creative professional | Animated hero with role rotator, services grid with detail pop-ups, animated skill bars, sports section, WhatsApp / email / phone contact, scroll progress bar, mobile layout | HTML, CSS, vanilla JavaScript |
| [Fitgurukannada — Fitness Coaching](fitgurukannada/) | Lead-capture site for a fitness coach | Multi-step consultation booking form (goal, details, lifestyle and health, progress photo), client- and server-side validation (18+ only), booking sent to the coach's WhatsApp, uploaded photos blocked from public access | HTML, CSS, JavaScript, PHP |
| [KAILEX Technologies](kailex/) | Website for my own technology venture | Services catalogue with pricing in an accordion, founders section, consultancy booking form | HTML, CSS, vanilla JavaScript |
